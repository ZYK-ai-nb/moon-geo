# MoonGeo：鲁棒二维空间查询库（申报草稿）

- 项目仓库：https://github.com/ZYK-ai-nb/moon-geo；发布、公开可访问性和 CI 证据见 `docs/release-0.1.0.md`。
- 参赛计划：按 11 月准备，具体日期和材料以该期官方通知为准；不沿用十月截止日期。
- 实际需求：地图服务区、编辑器区域选择等场景需要区分内部／边界／外部，处理凹形和孔洞，并在区域修改后维持正确查询。
- 已有基础：交接时为零实现 MoonBit 脚手架；本次已完成几何类型、可靠方向判定、线段分类、简单环与孔洞校验、点定位、面积／质心／距离和凸包。
- 索引与整合：动态 R-tree 已实现二次分裂、删除下溢重插和根收缩；区域查询先筛包围盒再判真实区域，提供 component／ring／edge 诊断和版本号。
- 技术路径：浮点误差筛选后，用 core/bigint 解码并精确计算二进制有理数的方向符号。测量值保持浮点近似，不声称精确面积或地理距离。
- 差异说明：MoonBit 已有几何、网格、STR-tree 和位置编码项目。本项目集中于可靠符号回退、动态结构维护、边界语义和可复核的区域候选精化；不宣称首创成熟算法或生态首个。
- 测试：手算与边界案例、四类 QuickCheck 属性、180 条独立 Fraction 符号数据、500 矩形范围查询和 1,000 次混合索引操作；以随附实测记录为准。
- 示例与文档：三个可运行示例、区域查询入口、API 接口文件、算法契约、相关工作及来源说明。
- 边界：只接收同一平面单位的有限坐标且绝对值不超过 1e100；不做经纬度投影、KD-tree、geohash、kNN、多边形布尔和可视化。
- 语言与许可：主要实现为 MoonBit，仅依赖标准库；Apache-2.0。算法参考 Shewchuk、Guttman 和经典几何文献，来源及独立实现范围已说明。
- 发布模块：`ZYK-ai-nb/moon-geo@0.1.0`；不得把工程测试或发布结果写成已经通过官方初审或验收。报名表尚未提交。
