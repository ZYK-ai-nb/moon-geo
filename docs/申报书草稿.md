## 一、实际需求与目标

地图服务区和编辑器需要判断位置属于哪些区域。近共线坐标可能造成普通浮点计算误判；凹多边形与孔洞也会使包围盒查询产生误命中。MoonGeo 以 MoonBit 实现可复用的二维空间查询，区分内部、边界和外部，并提供可检查的边界信息。

## 二、本期实现与技术路线

项目以 MoonBit 脚手架为起点，十月新增实现：

1. **可靠几何判定**：提供方向、线段关系和点在多边形内的三态判定，处理端点触碰、共线重叠和零长度线段。方向判定先做浮点误差筛选，在结果不确定时用 MoonBit 标准库 BigInt 精确计算输入二进制值的方向符号。
2. **动态空间索引**：实现 R-tree 插入、删除和范围查询，支持节点二次分裂、删除后重整和结构检查。
3. **区域查询与诊断**：先筛选包围盒，再判断实际区域；识别孔洞与凹形区域带来的误命中，并返回边界环、边编号及索引版本信息。

## 三、实际效果与验证

示例中，外环为 `(0,0)` 至 `(10,10)`、孔洞为 `(2,2)` 至 `(4,4)` 的服务区，对 `(1,1)`、`(3,3)`、`(2,3)` 分别得到内部、外部、边界结果。可通过 `moon run cmd/main --target js` 复现。

项目已发布 Mooncakes，包含 README、三个运行示例和测试。[GitHub Actions](https://github.com/ZYK-ai-nb/moon-geo/actions/runs/40997913421) 在 Wasm、Wasm-GC、JS、Linux Native 四个后端分别通过 91 项测试；180 个 Python Fraction 独立方向符号案例用于核对数值判定，动态索引也与逐项扫描进行对照。提交验收前将整理复现说明并核对最新 CI 状态。

## 四、差异与范围

MoonBit 已有几何与空间索引项目，如 [MoonGeoKit](https://github.com/cn-xjr/moongeokit/tree/0300c9cd7600c255011ddae96c9f7d929679e18a) 和 [MoonSTRtree](https://github.com/LING71671/MoonSTRtree/tree/de80237446811162f932c78792ad7ed82992f3ab)。MoonGeo 聚焦精确方向符号回退、动态 R-tree 维护、区域精化与边界诊断的组合；相关工作与可核验差异详见仓库文档。

项目参考 Shewchuk 鲁棒谓词思路、Guttman R-tree 论文及经典几何算法，来源和实现范围已记录。运行库仅依赖 MoonBit 标准库；处理同一平面坐标系下的有限坐标，面积、质心与距离为浮点近似。经纬度投影、多边形布尔运算和可视化不属于本期范围。
